# Smart Medicine Reminder

Interactive Python Streamlit web application designed to help users schedule medication routines, track daily doses, and receive timely patient reminders.

---

## 📌 Features

- **Medication Scheduling:** Easily add medicines, dosages, timings, and instructions.
- **Interactive Tracking:** Mark medicines as taken or pending throughout the day.
- **CSV Data Persistence:** Automatically saves patient medication records in structured CSV format.
- **Clean User Interface:** Built with Streamlit for intuitive navigation.

---

## 🛠️ Tech Stack

- **Language:** Python
- **Framework:** Streamlit
- **Data Processing:** Pandas, CSV
